# Djomoa Core Architecture

## Overview
Golden Calendar Chronology Engine.

## Core Modules

- SolarEngine
  Solar calendar calculations.

- LunarEngine
  Lunar cycle calculations.

- WeekEngine
  Weekly synchronization.

- ChronologyEngine
  Unified solar/lunar chronology.

- TimeEngine
  High level time queries.

## Supported Range

1 - 50000 Solar Years
